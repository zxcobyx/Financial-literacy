# Финансовая грамотность

## Описание
Это приложение для финансовой грамотности, которое помогает пользователям управлять своим бюджетом с помощью различных методов. Пользователи могут вводить свои доходы и получать рекомендации по распределению средств.

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone <URL>
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd Financial-literacy
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование
1. Запустите приложение:
   ```bash
   python main.py
   ```
2. На главном экране нажмите кнопку "Начать", чтобы открыть диалог для ввода дохода.
3. Введите свой доход и выберите метод бюджета.
4. Нажмите кнопку "Рассчитать", чтобы получить результаты.

## Методы бюджета
- **6 кувшинов**: Метод, который делит доход на шесть категорий расходов.
- **50/30/20**: Метод, который распределяет доход на 50% необходимых расходов, 30% желаний и 20% сбережений.
